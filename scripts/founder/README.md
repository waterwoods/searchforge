# Founder Scripts — Unified Intake

**Purpose:** Discoverable entry points for founders rehearsing demos and trials.  
**Product path:** Same scripts as `scripts/` root — wrappers only, no behavior change.

| Script | When |
|--------|------|
| `run_demo_local.sh` | Start local workbench |
| `demo_pre_checklist.sh` | Pre-demo checklist |
| `founder_pre_trial_checklist.sh` | Rehearsal depth path |
