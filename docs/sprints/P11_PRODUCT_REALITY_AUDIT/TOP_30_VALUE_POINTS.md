# TOP 30 Value Points — Chen Kui Perspective

**Persona:** Chen Kui — California auto insurance broker, Chinese-speaking clients, WeChat-heavy office, assistant handles daily follow-ups.  
**Method:** Before vs after using Unified Intake for 7 days. Ranked High / Medium / Low for willingness to pay.

---

## Before using the product

| Reality | Pain |
|---------|------|
| Customer messages arrive messy — mixed Chinese/English, carrier notices pasted inline | Must read entire thread to understand urgency |
| Cancellation / payment failure notices feel urgent but get buried | Risk of missed same-day deadline |
| "I already sent that document" — customer frustrated, broker re-asks | Trust erosion + wasted messages |
| Add-car quotes need year, model, zip across multiple WeChat turns | Easy to lose what's collected vs still needed |
| Every reply written from scratch in WeChat | 5–15 minutes per complex message |
| Follow-ups mean re-reading old context | No single "where we left off" view |
| Assistant asks broker "what should I tell them?" | Broker is bottleneck |
| Urgent vs can-wait mixed in same chat list | No operational queue |

---

## After using the product (when it works)

| Change | Value |
|--------|-------|
| One paste → case focus + urgency visible | Know "what this is" in seconds |
| **Your next move** on screen | Assistant can act without broker re-explaining |
| **Collected / Still needed** chips | Stop re-asking; ask only for gaps |
| Draft reply ready to edit | Copy to WeChat instead of blank page |
| Reopen + paste follow-up | Context preserved across days |
| Same-day action queue | Cancellation cases don't get buried |
| Human confirmation badge | Know when to double-check AI-collected facts |
| Demo queue for training | Safe learning without real customer data |

## What actually changes for Chen Kui?

**If value lands:** The assistant spends less time asking Chen "what should I reply?" and Chen spends less time re-reading WeChat for cancellation and missing-doc cases. Replies go out faster with fewer wrong re-asks.

**If value does NOT land:** Paste feels like extra work, first screen confuses, draft quality inconsistent — Chen goes back to WeChat-only workflow by Day 3.

**Highest-ROI scenarios for payment:** Cancellation risk (#1), missing document (#8), draft reply (#3). Add-car (#9) is revenue-positive but secondary to urgency triage.
