**Perspective:** What founders should change after assuming P6–P10 complete and reading customer truth.

---

## What founders should STOP doing

1. **Stop** dropping a URL and expecting Chen Kui to find 办公室工作台 alone  
2. **Stop** referencing SIM1–SIM3, PG mirror, or API endpoints with brokers  
3. **Stop** leading demos on 客户报送 / Add-Car when pain is cancellation triage  
4. **Stop** treating `trial_launch_check.sh` PASS as "broker-ready" without UI walkthrough  
5. **Stop** running broker trials on localhost without explaining persistence limits  
6. **Stop** promising Add-Car portal maturity for cancellation-first buyers  
7. **Stop** sprint archaeology, repo cleanup, and lab isolation during trial weeks  
8. **Stop** adding features before one broker completes 7 days with logged evidence  
9. **Stop** hiding pricing — broker asks "then what?" on Day 3  
10. **Stop** assuming ChatGPT comparison doesn't happen — prove case structure value

## What founders should KEEP doing

1. **Keep** the core promise: paste → case → draft → you send  
2. **Keep** 7-day trial with observation log + fix-now queue  
3. **Keep** guardrail before every demo/trial (`guardrail_inbox_triage.sh`)  
4. **Keep** explicit "what we don't promise" (no WeChat sync, no auto-send)  
5. **Keep** founder Day 0 kickoff (30 min) until UI fixes prove unsupervised Day 1  
6. **Keep** CUSTOMER_LANGUAGE_GUIDE — apply it in UI copy, not just docs  
7. **Keep** manual payment (WeChat/Zelle) for first pilot — speed over Stripe  
8. **Keep** TRIAL_ONE_PATH as single trial entry — don't fork playbooks  
9. **Keep** Copy case snapshot workflow for L2 support  
10. **Keep** cancellation → missing doc → add-car demo triangle  

---

## What founders should OBSESS over

1. **First 5 minutes** — broker sees cancellation urgency without founder translating  
2. **One real case "worked" line** — logged date, scenario, minutes saved (even approximate)  
3. **Draft copied with edits** — behavioral proof, not demo applause  
4. **Days opened ≥4 of 7** — retention beats feature count  
5. **Engineer chrome zero** in product-only UI — trust is visual  
6. **Production `/readyz`** — cases persist; no "it worked yesterday on my laptop"  
7. **Day 7 payment conversation** — invoice + terms ready before trial starts  
8. **Assistant adoption** — if only broker uses it, value ceiling is low  
9. **Fix-now queue discipline** — top friction shipped or explicitly deferred to broker  
10. **Second broker readiness** — first testimonial unlocks next sale
