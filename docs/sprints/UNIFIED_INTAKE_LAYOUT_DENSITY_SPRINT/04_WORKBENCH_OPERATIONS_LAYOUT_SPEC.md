# Workbench Density / Operations Layout Spec

## Screen usage

- **≥lg / xl:** Two-column **operations layout**:
  - **Left (narrower):** Demo queue + KPI strip + **recent case queue** (sticky, scrollable).
  - **Right (wider):** Console header + paste/triage + **active case sheet**.

## Above the fold

- **Queue counts / demo controls** visible without scrolling past paste.
- **“立即处理”** bucket visible when cases exist (left column).

## Module arrangement

- **State-first:** Queue and attention buckets before deep case editing on wide screens.
- **Action path:** Paste → triage → case sheet remains linear on the **right** rail.

## Status / next-step presentation

- Keep existing tags and “您的下一步” prominence; framing is **sectioned** by cards and column split—not new logic.

## Operational console feel

- Sticky queue column mimics **tooling panels** (tickets, shipments, monitoring lists): always reachable while editing.
