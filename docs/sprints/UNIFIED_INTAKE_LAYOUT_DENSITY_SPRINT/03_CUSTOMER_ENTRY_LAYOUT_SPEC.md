# Customer Entry Density / Layout Spec

## Target width

- **Content column:** ~**920px** max (wider than a “floating note card,” narrower than full-bleed chaos).
- **Portal frame:** Single white **contained surface** (border + soft shadow) so the page reads as one product, not scattered boxes on gray.

## Card containment

- Hero/trust block remains **first** inside the portal.
- Primary actions (quick-start grid) are **one module** with clear heading.
- Conversation + composer stay **grouped**; avoid orphan inputs below unrelated whitespace.

## Trust block

- Top of portal; single statement of **response expectation** + **privacy/trust boundary** (existing copy, tightened visually).

## Free input placement

- Below action grid when empty; when in-thread, composer stays **anchored** under transcript with consistent card styling.

## Appropriate density

- **Lower** than workbench: fewer simultaneous modules, more vertical rhythm, no queue column.

## Reducing “floating” feeling

- Remove “narrow island on infinite gray”: use **portal shell** + aligned page chrome so the eye reads **one intentional surface**.
