# Visual Reference Mix Spec

## Stripe-like (Customer Entry)

**Borrow:** Card hierarchy, restrained shadow, clear hero/trust block, bounded content width, purposeful whitespace, “service portal” framing.  
**Do not copy:** Stripe’s marketing mega-pages, pricing tables, or developer-docs density.

## Amazon-style operational UI (Workbench)

**Borrow:** Multi-column work areas, above-the-fold scan of “inventory” (queue), dense but labeled modules, functional chrome.  
**Do not copy:** Retail chrome, ads, or unrelated global nav.

## Medical / professional monitoring principles (Workbench)

**Borrow:** Persistent status visibility, high-signal labels, section framing, “nothing ambiguous is hiding.”  
**Do not copy:** Clinical alarm chrome, ultra-dense vitals grids, or customer-facing severity styling on the intake side.

## Recommended mix (this product)

| Surface | Primary | Secondary |
|---------|---------|-----------|
| Customer Entry | Stripe-like portal | — |
| Broker Workbench | Amazon-style layout | Med-monitor clarity for status/queue |

## Final rule

**Customer = trust + guidance.** **Workbench = state + throughput.** Same brand, different density.
