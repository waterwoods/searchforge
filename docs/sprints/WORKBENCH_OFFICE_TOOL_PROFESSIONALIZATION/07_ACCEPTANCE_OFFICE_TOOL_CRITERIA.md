# Acceptance / Office Tool Criteria

**Sprint:** Workbench Office Tool Professionalization

---

## 1. Stronger Office-Tool Feel

- [ ] Workbench feels like a real broker office case-review surface
- [ ] Queue cards support 3–5 second scan
- [ ] Case detail feels like a working case sheet, not a debug panel

---

## 2. Faster Scanability

- [ ] Broker sees case focus, quote-ready, contact, correction/already_sent on queue card
- [ ] Broker sees next-step preview on queue card
- [ ] Broker sees follow-up (waiting_on, due-state) on queue card

---

## 3. Reduced Blind Spots

- [ ] Correction / already_sent visible on queue card
- [ ] Contact needed visible when quote-ready but no name/phone
- [ ] Due today / overdue visible on queue card

---

## 4. Stronger Follow-Up Visibility

- [ ] waiting_on / next_contact_by visible on queue card when set
- [ ] Due-state (overdue / due today / due tomorrow) prominent
- [ ] Follow-up block in case detail above fold

---

## 5. Stronger Commercial Product Feel

- [ ] broker_next_step feels like real office instruction
- [ ] No vague "Review and act on" fallbacks in production paths
- [ ] Queue and case detail feel intentional, not ad-hoc

---

*End of criteria*
