# Founder Demo / Inspection Notes

**Sprint:** Minimal Business Rules Center for Add-Car Quote  
**Purpose:** What the founder should inspect and what would prove usefulness.

---

## 1. What the Founder Should Inspect

1. **Open Rules Center** — Workbench → Add-Car Rules (or Rules Center)
2. **View current rules** — See first reply, next-step prompts, handoff
3. **Edit one rule** — Change first reply (中文) to something slightly different
4. **Preview** — Type "我想加一台X5" → see system reply
5. **Publish** — Click Publish; confirm
6. **Verify live** — Unified Intake → type same message → see updated reply

---

## 2. What a Business User Should Be Able to Do

- Understand the page without engineering context
- Edit a rule safely (draft only)
- Preview a sample input
- See the result of the rule change
- Publish when ready

---

## 3. What Would Prove This Is Useful vs Confusing

**Useful:**
- Chen Kui can change "先把年份和车型发我" to something else and see it in preview
- No deploy required
- No code changes

**Confusing:**
- Technical jargon exposed
- Too many fields
- Preview unclear or broken
