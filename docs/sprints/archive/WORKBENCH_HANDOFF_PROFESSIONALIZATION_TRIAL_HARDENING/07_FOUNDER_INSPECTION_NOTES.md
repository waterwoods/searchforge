# Founder Inspection Notes

**Sprint:** Workbench Handoff Professionalization + Trial Hardening

---

## 1. What Founder Should Inspect After This Sprint

1. **First-scan clarity** — Open a case; can you understand it in 3–5 seconds?
2. **Key signal visibility** — Quote-ready, contact, attachment, correction, already_sent
3. **Next-step usefulness** — Does broker_next_step feel like a real office instruction?
4. **Queue card scan** — Can you prioritize from the list without opening every case?

---

## 2. Which Cases to Open First

1. **Cancellation risk** — Same-day action; broker_next_step should say "today"
2. **Missing document + already_sent** — Should show "Verify receipt" and already_sent badge
3. **Add-car quote-ready** — Should show quote_ready tag, contact block, next step with vehicle
4. **Add-car correction** — Should show correction badge, updated collected fields
5. **Premium review** — Should show remove-vehicle or renewal context

---

## 3. What "Good Enough to Show a Real Broker Office" Looks Like

- Broker opens workbench → sees queue with clear labels (Quote-ready, Verify receipt, Action now)
- Broker opens case → sees "Your next move" immediately, no scrolling to find it
- Broker sees correction / already_sent when relevant — no surprise after re-reading
- Broker sees contact/attachment status — knows if follow-up is blocked

---

## 4. What to Watch For

- **Overcrowding** — Too many tags; hard to scan
- **Vague next steps** — "Continue processing" instead of concrete action
- **Buried signals** — Correction or already_sent hidden in text
- **Queue cards** — Can you tell quote-ready vs need-more without opening?
