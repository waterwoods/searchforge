# High-Value Question Realism + Product Polish — Sprint Blueprint

**Sprint:** High-Value Question Realism + Product Polish  
**Created:** 2026-03-14  
**Target:** 20–45 min execution

---

## 1. Why This Sprint Matters Now

The product has:
- 25-question corpus base
- 8 selected high-value productized question types
- Routing (FAST / LLM / human)
- Simulation scenarios, handoff structure, trust boundaries

**Next highest-value move:** Make these selected question types more realistic, first-person, emotionally believable, and demo/pilot convincing — then redeploy so the founder can inspect.

---

## 2. Why Realism of Top 5–8 Question Types Matters Commercially

| Factor | Impact |
|--------|--------|
| **Demo credibility** | Chen Kui judges "would my clients actually say this?" |
| **Pilot adoption** | Real phrasing → broker trusts the system handles real office traffic |
| **Trust boundary clarity** | Office-safe wording → broker knows when to verify |
| **First paid pilot** | Strongest scenarios drive "I'd use this" decision |

---

## 3. What "Good Enough" Realism Looks Like

- **More realistic:** First-person direct customer wording; natural short openings; believable life context; appropriate emotional tone
- **Less generic:** No label-like, test-case-like wording; no third-person "客户说…" when customer would speak directly
- **Office-ready:** Clear "still need to collect"; tighter trust boundary wording; broker-natural response style
