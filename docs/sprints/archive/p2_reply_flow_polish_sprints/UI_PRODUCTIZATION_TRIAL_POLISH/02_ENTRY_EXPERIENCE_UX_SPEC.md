# Entry Experience UX Spec

**Purpose:** Define how Customer Entry should feel for trial and sale.

---

## 1. What Users See First

- **Above the fold:** A clear welcome message (Chinese or bilingual depending on audience).
- **Primary action:** Quick-start buttons for common intents (报价, 变更, 事故, 付款, 材料, 联系人工).
- **Secondary action:** Free-text input for pasting or typing.
- **Trust cue:** Short reassurance that the message goes to the office and will be handled promptly.

---

## 2. Welcome Area

- **Headline:** "今天有什么可以帮您？" (or equivalent) — friendly, not generic.
- **Subtext:** Explain that the user can choose a topic or type freely; mention human handoff if needed.
- **Trust:** "您的消息会直接转给办公室，我们会尽快帮您处理。"

---

## 3. Action/Button Hierarchy

- **Primary:** Quick-start buttons (8–10) — visible, tappable, clear labels.
- **Secondary:** Submit/Send button — prominent when input has content.
- **Tertiary:** "不确定说什么？点这里看示例" — available but not competing for attention.
- **Simulation:** "模拟演示" — small, text-style, for founder demo only.

---

## 4. Example Visibility

- Examples should be behind a toggle (e.g. "不确定说什么？点这里看示例").
- When expanded, examples should be grouped and labeled (e.g. Payment failed, Missing document, Add car).
- Each example should have a short purpose label so the user understands what it demonstrates.

---

## 5. Chat Layout

- Customer messages: right-aligned, distinct color (e.g. blue tint).
- System/office messages: left-aligned, distinct color (e.g. green tint).
- Role labels: "您" / "办公室" — small, readable.
- Tags (urgency, status): only when relevant; not overwhelming.

---

## 6. Case Summary (During Collection)

- When triage is in progress, show a compact "Case Summary" card.
- Labels: 主题, 已收集, 还需, 下一步建议 — in Chinese where possible.
- Avoid internal jargon ("Case Summary" in English is acceptable; prefer "整理中" or similar).

---

## 7. Handoff Ready State

- Clear success state: "办公室会尽快处理，有结果会联系您。"
- Primary action: "查看工作台" — for broker handoff.
- Secondary: "提交新问题" — for next conversation.

---

## 8. Product Feel

- No "Unified Intake" or internal labels in customer-facing text.
- No "demo mode" or "simulation" labels visible to end customers.
- No build/version info in customer view.
- Consistent spacing and grouping; no cramped or cluttered layouts.

---

*End of Entry Experience UX Spec*
