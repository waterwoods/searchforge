# Acceptance / Professional Screen Criteria

## Must improve

- [ ] **Workbench** uses **horizontal** space on wide viewports (queue + workflow visible together).
- [ ] **Customer** reads as **one portal surface**, not a narrow strip in empty gray.
- [ ] **Page chrome** states product context (统一入口 / office vs customer) without clutter.

## Screen utilization

- [ ] No **default** state where >50% width is unused **without** intentional margin (customer may be narrower by spec; still **framed**).

## Professionalism

- [ ] Modules have **clear boundaries** (border/shadow/section break).
- [ ] Workbench feels **operational**; customer feels **trust-oriented**.

## Appropriateness

- [ ] Customer **not** as dense as workbench.
- [ ] Workbench **not** as sparse as a landing page.

## Build

- [ ] `npm run build` passes.
