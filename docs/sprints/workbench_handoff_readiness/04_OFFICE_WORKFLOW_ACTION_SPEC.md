# Office Workflow / Action Spec

**Sprint:** Workbench Handoff Readiness  
**Purpose:** Define what an assistant should do when opening a handed-off case.

---

## 1. When Opening a Handed-Off Case

| Step | What broker should see immediately | Must-have vs nice-to-have |
|------|-----------------------------------|---------------------------|
| 1 | What the case is about (case focus) | Must-have |
| 2 | What the customer most recently said (2–3 messages) | Must-have |
| 3 | What is collected | Must-have |
| 4 | What is still needed | Must-have |
| 5 | What the office should do next | Must-have |
| 6 | Lifecycle / handoff stage | Must-have |
| 7 | Correction / "already sent" hint if present | Must-have |
| 8 | Full conversation for verification | Nice-to-have (below fold) |

---

## 2. What Should Be Visible Without Extra Clicking

- Recent customer messages
- Collected / still needed
- Next move
- Lifecycle status
- Correction badge
