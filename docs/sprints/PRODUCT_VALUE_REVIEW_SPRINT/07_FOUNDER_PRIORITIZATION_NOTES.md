## 2. How to Use This Framework for Future Sprint Choices

1. **Before each sprint:** List candidate directions.
2. **Score each** on: Commercial, Broker, Customer, Reuse, Cost, Risk, Urgency.
3. **Challenge:** Are we overvaluing technical novelty? Undervaluing trial?
4. **Rank:** Top / mid / defer.
5. **Choose one** as next sprint.
6. **Document** what was deferred and why.
