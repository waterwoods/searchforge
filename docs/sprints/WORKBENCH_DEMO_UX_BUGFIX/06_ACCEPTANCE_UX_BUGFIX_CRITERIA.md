# Acceptance / UX Bugfix Criteria

**Sprint:** Workbench Demo UX + Visual Bug Fix Sprint

---

## 1. Queue Load Clarity

- [ ] Button shows loading state during load
- [ ] Success: toast in Chinese; Tag updates to green when 13/13
- [ ] Failure: Alert visible; toast error; button re-enabled
- [ ] Already-ready: toast in Chinese; no confusion
- [ ] Founder can tell whether load succeeded or failed

---

## 2. Readable Cards

- [ ] 最近 case cards readable without highlighting text
- [ ] Tags readable (sufficient contrast)
- [ ] Preview text and "最近" line readable
- [ ] Section headings (立即处理, 等待或暂存) readable

---

## 3. Readable Labels/Tags

- [ ] Summary stat cards (需立即处理, etc.) readable
- [ ] Demo queue Tag (X/13 个 case 已就绪) readable
- [ ] Case card tags (case focus, attention, readiness) readable

---

## 4. Stronger Demo Confidence

- [ ] Workbench feels more stable
- [ ] Lower broken-MVP feel
- [ ] Founder can complete demo path without guessing

---

## 5. Deferred (Out of Scope)

- Pixel-perfect polish
- Full theme redesign
- Backend changes
- Simulation Assistant changes
