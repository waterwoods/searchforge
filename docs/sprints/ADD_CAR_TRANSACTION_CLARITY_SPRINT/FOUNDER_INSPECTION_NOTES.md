# Founder Inspection Notes

Use this checklist when clicking through **客户服务入口** (Unified Intake).

## Add-Car — transaction identity

1. Start **获取报价** or hybrid form — after first reply, confirm **蓝色/浅色事务条** shows **当前办理：加车报价**.  
2. Confirm progress card title reads **加车报价 · 进度** (while not yet handed off).  
3. Confirm input area shows **当前办理** + **加车报价** tag (not only generic 主题).

## Add-Car — closure

1. Drive to `handoff_ready` (full vehicle + zip + driver + delivery per rules).  
2. Confirm green panel **headline** appears above the office reply.  
3. Read **second line** — office processing / no duplicate submit.  
4. Read **boundary** — other questions → **提交新问题**.  
5. Toast should feel like **已交办公室**, not only “我们会处理”.

## Non–Add-Car sanity

1. Start **付款 / 账单** or **联系人工** — handoff panel should show **generic** closure headline (not 加车-specific).  
2. No empty ribbon when not Add-Car.

## Workbench

1. Paste add-car thread → **加车报价** tag + optional **事务** context line under tags.

## If something fails

Note: scenario id, screenshot path, and whether **UI vs API copy** vs **triage** is wrong.
