# Product / Sales Readiness Blueprint

**Sprint:** Sales Readiness Hardening Sprint  
**Created:** 2026-03-17  
**Scope:** SearchForge → Chen Kui Insurance Unified Entry

---

## 1. Why This Hardening Matters Now

The product has:
- Strong backbone (workflow_state, multi-turn continuity)
- Strong high-frequency scenarios (add-car, payment, missing doc, renewal, claim)
- Clear sellable standard package (7 scenarios)
- Office-usable workbench (Recent messages, Collected/Still needed, correction badges)

**But** the founder correctly identifies:
- Talk to Agent still feels like a thin escape hatch, not a real product capability
- A few edge cases still feel unfinished
- The package is clearer on paper, but some product behaviors do not feel strong enough in real use

**That means:** The next most valuable move is **sales-readiness hardening**, not broad expansion.

---

## 2. Why This Is the Correct Move After Package Definition

| Prior move | Outcome |
|------------|---------|
| Package definition | Clear 7-scenario offer; demo path; what broker gets |
| This sprint | Strengthen the last visibly weak points that most affect trial trust |

Package clarity ≠ product strength. A prospect can now *explain* the offer, but if Talk to Agent feels weak or edge cases break trust, the product still feels MVP-ish in real use.

---

## 3. What This Sprint Will Strengthen

| Area | Target |
|------|--------|
| **Talk to Agent** | Formal upgrade path into office support; not a weak escape hatch |
| **Edge cases** | 2–3 most commercially important: billing "我发你了", late correction, mixed-intent + human |
| **Handoff / office** | More complete payload; clearer context; next action visible |
| **Trust** | Fewer obvious trust-breaking moments; product feels stronger, not just better packaged |

---

## 4. What This Sprint Intentionally Will NOT Do

- Add broad new features
- Open giant platform scope
- Average effort across many loose improvements
- Solve every edge case
- Add inbox/WeChat integration, OCR, multi-tenant, Stripe

---

## 5. Success Definition

At the end of this sprint:
1. Talk to Agent feels like a **real service capability**
2. High-risk edge cases that affect trust are **handled better**
3. Handoff payload / office visibility is **more complete** where needed
4. The product feels **stronger**, not just better packaged

---

*End of Product / Sales Readiness Blueprint*
