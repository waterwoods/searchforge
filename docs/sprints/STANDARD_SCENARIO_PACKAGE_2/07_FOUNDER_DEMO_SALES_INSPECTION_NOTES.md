## 2. Which Package Flows Best Demonstrate 2.0 Improvement

1. **Material / already sent** — "Client says sent" → summary and broker_next_step now tell broker exactly what to verify
2. **Payment / already paid** — Same: broker knows to confirm with carrier
3. **Add-car** — Summary "Collected" chips more accurate; broker sees year, model, zip at a glance
4. **Renewal** — When client sends bill, hand off with "policy/bill sent" in summary

## 3. What Should Now Feel More Sellable Than Before

- "One paste → structured case" is **more complete** (summary + next step + chips)
- Broker gets **clearer verification guidance** when client says "sent" or "paid"
- Package feels **less MVP-like** — handoff is more useful, not just "we have handoff"
- Founder can say: "When the client says they already sent the document, the system tells you exactly what to verify with the carrier."
