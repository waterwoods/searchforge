# Customer Intake Page Structure Spec

**Sprint**: Unified Intake UI Professionalization

---

## First-Screen Structure (3 Layers)

### Layer 1 — Trust / Hero
- **Purpose**: Explain what this page helps with; that the office will follow up; that customer information will be handled and reviewed
- **Content**: Short headline (e.g., "陈奎保险 · 客户服务入口"); subtext with trust messaging
- **Placement**: Top of page, above the fold
- **Spacing**: Generous padding; clear separation from Layer 2

### Layer 2 — Primary Entry Actions
- **Purpose**: Main business actions as intentional service entry points
- **Actions**: 获取报价, 保单变更, 报事故, 上传材料, 联系人工
- **Form**: Cards or modules, not random small buttons
- **Placement**: Immediately below hero; primary visual focus
- **Spacing**: Clear gaps between action modules; consistent sizing

### Layer 3 — Free Input
- **Purpose**: Secondary path for "not sure which to choose"
- **Form**: Textarea + submit; clearly labeled as fallback
- **Placement**: Below primary actions; does NOT dominate page identity
- **Spacing**: Contained in a card; visually subordinate to Layer 2

---

## Block Organization

| Block | Primary/Secondary | Notes |
|-------|-------------------|-------|
| Trust / Hero | Primary | First thing customer sees |
| Primary entry actions | Primary | Main interaction surface |
| Free input | Secondary | Fallback, not hero |
| Examples / hints | Tertiary | Collapsible or subtle |

---

## Spacing / Block Rules

- Section gaps: 24–32px between major blocks
- Card internal padding: 20–24px
- Max content width: 720–800px, centered
- Page background: Soft light gray (#f5f5f5 or #f8f9fa)
