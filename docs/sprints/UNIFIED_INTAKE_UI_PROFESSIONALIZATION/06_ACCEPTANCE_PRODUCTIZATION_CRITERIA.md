# Acceptance / Productization Criteria

**Sprint**: Unified Intake UI Professionalization

---

## Reduced Demo Feel

- [ ] "模拟演示" not competing with primary entry on first screen
- [ ] No internal/workbench terminology above the fold
- [ ] Page feels like customer service entry, not lab tool

---

## Stronger Trust

- [ ] Trust messaging visible in hero/above fold
- [ ] "办公室会跟进" or equivalent explicit
- [ ] No white-on-light or dark-theme color bugs

---

## Clearer Page Hierarchy

- [ ] Layer 1 (Trust) → Layer 2 (Actions) → Layer 3 (Free input) order
- [ ] Primary actions visually dominant over free input on first screen
- [ ] Consistent section separation

---

## Stronger Primary Path

- [ ] 6 entry actions feel like deliberate service entry points
- [ ] Actions not scattered chips; cards or prominent buttons
- [ ] Free input labeled as secondary/fallback

---

## More Professional Overall Look

- [ ] White cards, light gray page background
- [ ] Clear card boundaries
- [ ] Consistent spacing
- [ ] Typography hierarchy (title > body > secondary)
