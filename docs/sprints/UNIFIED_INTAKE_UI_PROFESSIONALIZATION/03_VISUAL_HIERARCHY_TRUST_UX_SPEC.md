# Visual Hierarchy / Trust UX Spec

**Sprint**: Unified Intake UI Professionalization

---

## Typography Hierarchy

| Level | Use | Size | Weight |
|-------|-----|------|--------|
| H1 | Page / hero title | 24–28px | 600 |
| H2 | Section titles | 18–20px | 600 |
| Body | Trust copy, descriptions | 15–16px | 400 |
| Secondary | Hints, labels | 13–14px | 400 |
| Caption | Tertiary info | 12px | 400 |

---

## Card Structure

- **Background**: White (#fff) or very light (#fafafa)
- **Border**: 1px solid #e8e8e8 or #f0f0f0
- **Border radius**: 8–12px
- **Shadow**: Optional subtle (0 1px 2px rgba(0,0,0,0.04))
- **Padding**: 20–24px internal

---

## Section Boundaries

- Clear visual separation between Trust, Actions, Free Input
- Use background contrast: page #f5f5f5, cards #fff
- No awkward white/black split; avoid dark-theme remnants

---

## Color Direction

- **Primary accent**: Deep blue (#1890ff or #1677ff) — trusted, formal
- **Success / handoff**: Green (#52c41a)
- **Warning / urgency**: Orange (#fa8c16)
- **Text primary**: #262626
- **Text secondary**: #8c8c8c
- **Page background**: #f5f5f5 or #f8f9fa

---

## Trust Messaging

- Above the fold: "您的消息会直接转给办公室，我们会尽快帮您处理。"
- Optional: "信息会妥善处理，办公室会在1–3个工作日内跟进。"
- Avoid internal/demo terminology on first screen

---

## "Formal Product" Feel

- Clean, guided, business-like
- Non-engineering, non-demo
- Consistent spacing and typography
- No visual fragmentation
