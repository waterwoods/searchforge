# Portal feel vs chat feel — checklist

Use when reviewing copy or future UI changes.

| Heuristic | Portal-friendly | Chat-demo tilt |
|-----------|-----------------|----------------|
| Opening | 请选择办理类型 / 报送 | 今天有什么可以帮您 |
| User content | 报送、提交 | 消息、发送 |
| System side | 办公室整理、记录 | 助手回复、对话 |
| Live feel | 状态随报送更新 | 实时更新、正在输入 |
| Primary CTA | 提交报送 / 提交补充 | 发送 |
| Outcome | 服务记录、办理摘要、跟进 | 回复、答案 |
| Recovery | 未完成的报送 | 恢复对话 |
| Tab | 客户报送 / 受理入口 | 客户入口 / 客户 |
