# Acceptance Criteria

- [ ] On **客户入口**, the main white customer-entry container’s **left edge** aligns with the white “统一服务入口” title strip and the tab row (no visible “shifted in” column).
- [ ] **办公室工作台** tab layout is unchanged in structure (no regression to density or queue UI).
- [ ] No backend or API changes.
- [ ] `npm run build` in `ui/` completes successfully.
- [ ] No new ESLint/TS issues in edited files.

## Non-goals (explicit)

- Redesigning typography, colors, or card hierarchy.
- Changing `UNIFIED_INTAKE_SHELL_MAX` or App shell header behavior.
- New features or demo queue logic.
