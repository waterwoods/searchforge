## What should stay in English if truly needed

- Technical field keys (e.g. `vin`, `make_model`) — internal; never shown
- Demo/example labels for founder use (lower priority)
- Logs, console, error codes

## Wording style guide for future UI

- Concise
- Professional
- Office-usable
- Customer-service / broker-office oriented
- Not engineering-heavy
- Not chatbot-ish
- Not internally debug-ish

Examples of good phrases:
- 已收集 / 还缺 / 下一步 / 跟进 / 在等 / 今日到期 / 已发材料
- 可行动 / 需更多信息 / 可报价 / 差一点 / 信息不足

## What wording should be avoided

- Awkward direct translations
- Mixed English/Chinese in same sentence when Chinese suffices
- Debug-style labels (e.g. "UW follow-up" → 核保跟进)
- Chatbot-ish phrasing ("I'll help you with...")
