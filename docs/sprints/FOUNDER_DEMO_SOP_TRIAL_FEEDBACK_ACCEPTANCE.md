# Founder Demo SOP + Real Trial Feedback — Acceptance / SLA Criteria

**Sprint:** Founder Demo SOP + Real Trial Feedback Sprint  
**Created:** 2026-03-14

---

## What Must Be Clear to the Founder

| Criterion | Pass |
|-----------|------|
| Pre-demo steps | One command or short checklist; Andy knows what to run before demo |
| Which URL | Explicit: http://localhost:5173/workbench/unified-intake (or production) |
| What to say first | 30–60 second intro script; no overclaim |
| Which path to show | Primary path named; backup path named |
| Top 3 scenarios | SIM1, SIM2, SIM3 (or equivalent) in order |
| Fallback if slow | What to say if Turn 1 is slow; offline / Simulation Assistant fallback |
| "不自动发送" | Explicit mention: broker confirms before sending; nothing auto-sent |

---

## What Must Be Clear to a Prospect

| Criterion | Pass |
|-----------|------|
| Value proposition | One sentence: messy message → structured case → next move → draft reply |
| Broker in control | Human confirmation; nothing auto-sent |
| Collected / Still needed | Visible chips for add-car, renewal, claim, missing-doc |
| Case focus | Tag at top of action card |
| Which scenario to try first | Cancellation risk (urgency) |

---

## What Must Be Visible in the Demo

| Item | Where |
|------|-------|
| Case focus | Top of action card |
| Your next move | Bold, operational |
| Collected / Still needed | Green/orange chips |
| Human confirmation recommended | Badge when AI collected from conversation |
| Work now / Waiting or parked | Queue triage |
| Load founder demo queue | Button; seeds 13 cases; cancellation opens first |
| Simulation Assistant | Side panel; SIM1, SIM2, SIM3 in Recommended trial |

---

## What Counts as Trial-Blocking

- Prospect cannot understand what the system does
- Flow is confusing or output unreliable
- "不自动发送" / human confirmation not visible or not said
- Top 3 scenarios fail or look broken
- No feedback questions to ask after trial

---

## What Can Be Deferred

- Inbox sync, email/WeChat integration, OCR
- Full CRM, carrier integration, multi-tenant
- Stripe, billing
- Additional scenario polish beyond top 3
