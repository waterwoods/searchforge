# First 3 Customer Types (ICP ordering)

## Type 1 — “Chen Kui shaped” (reference ICP)

- **CA auto**, **Chinese-speaking** clients, **WeChat-heavy**.
- **Small office** (1–5), manual triage today.
- **Why first:** Goal doc and scenario pack already align; narrative is proven in-repo.

## Type 2 — Same segment, different voice (hot-plug proof)

- Another **CA auto** shop with same pain but different **tone / branding**.
- **Why second:** Validates **client pack** economics without new vertical risk.
- **Caution:** Engine leak audit must be respected—charge for **pack + setup**, not magic.

## Type 3 — Assistant-led desk under a busy producer

- Producer is rarely first reader; **assistant** pastes and hands off structured cases.
- **Why third:** Operator value spec is strongest here; success = **handoff quality**, not producer sitting in UI all day.

## Who to defer

- Multi-location rollouts requiring **tenant** isolation.
- Shops demanding **inbox integration** on day one.
- Non-auto or **non-CA** until two wins in niche.
