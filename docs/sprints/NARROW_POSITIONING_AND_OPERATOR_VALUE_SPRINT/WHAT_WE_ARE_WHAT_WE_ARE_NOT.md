# What We Are / What We Are Not

## What we are

| We are | In plain language |
|--------|-------------------|
| Intake organizer | One place to paste what the customer said |
| Triage assistant | Category + urgency to match how the office prioritizes |
| Handoff scaffold | “What to do next” + what we have / need |
| Draft starter | Client reply you edit before sending |
| Workbench | Queue, case focus, light follow-up memory (as shipped in standard package) |
| Configurable voice | Industry + client pack for same-segment brokers |

## What we are not

| We are not | Why it matters |
|------------|----------------|
| Full automation platform | Offices won’t believe it; you can’t deliver it |
| CRM | No system of record replacement |
| Carrier integration | No completing actions in carrier systems |
| OCR / screenshot AI | Explicit boundary—don’t demo-imply it |
| Auto-send bot | Trust and compliance break |
| Multi-vertical “AI for all insurance” | Kills focus and replication speed |

## One-line test

If a sentence makes us sound like we **run the agency**, delete it. If it sounds like we **clean up the front door**, keep it.
