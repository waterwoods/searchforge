# Trial Metrics / Success Criteria Spec

**Sprint:** Real Broker Trial Package Sprint  
**Created:** 2026-03-18

---

## 1. Metrics to Track During Trial

| Metric | How to measure | Why |
|--------|----------------|------|
| **Conversations started** | Count of pastes / cases created | Usage volume |
| **Cases created** | Count of handoffs | Core output |
| **Handoffs per scenario type** | By case focus (add-car, cancellation, missing-doc, etc.) | Which scenarios broker uses |
| **Average fields collected before handoff** | From Collected chips (add-car: year, model, zip) | Intake quality |
| **Manual follow-up questions still needed** | Broker self-report: "Did you have to ask again?" | Value: fewer re-asks |
| **Time to understand case** | Broker self-report: "How long to understand?" | Value: faster triage |
| **Draft usability** | Broker self-report: "Edit vs rewrite?" | Value: less writing |
| **Broker would use again** | Post-trial: "Would you use this tomorrow?" | Retention signal |

---

## 2. Practical Metrics (Easiest to Capture)

| Priority | Metric | How |
|----------|--------|-----|
| 1 | Number of conversations | Count cases in workbench |
| 2 | Number of handoffs | Same |
| 3 | Scenario mix | Case focus tags |
| 4 | Broker feedback (post-trial) | 5 value validation questions |

---

## 3. Success Criteria for Trial

**Trial success** means:
- Broker completed at least 5 conversations across 3+ scenario types
- Broker can answer: "Which scenario felt most useful?"
- Broker can answer: "Which part still feels risky?"
- Broker understands what the product does and does not do

**Trial failure** means:
- Broker cannot understand the flow
- Output feels unreliable or confusing
- Broker cannot tell what would happen in real office use

---

## 4. Value Validation Questions (Post-Trial)

1. Which scenario felt most useful to your office?
2. Which part still feels risky or not trustworthy?
3. Would this save you or your assistant time?
4. What would you want it to do next?
5. What would you be willing to try first in a pilot?
