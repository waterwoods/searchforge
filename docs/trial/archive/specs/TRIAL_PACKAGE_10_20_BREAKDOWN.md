# Real Broker Trial Package — 10–20 Point Breakdown

**Sprint:** Real Broker Trial Package Sprint  
**Created:** 2026-03-18

---

## Concrete Trial-Package Points

| # | Point | Decision |
|---|-------|----------|
| 1 | **Trial package name** | Real Broker Trial Package (Chen Kui 1-Week Pilot for client-specific) |
| 2 | **Target broker profile** | California auto broker, Chinese-speaking clients, 1–5 person office |
| 3 | **Target customers** | Broker's end customers (WeChat/email); broker pastes messages |
| 4 | **Included scenarios** | 5 core: Cancellation risk, Missing document, Add-car quote, Premium review, Claim intake |
| 5 | **Excluded/deferred scenarios** | Email/WeChat integration, OCR, full CRM, multi-tenant, Stripe, carrier API |
| 6 | **Why these scenarios** | Highest commercial value: urgency, operational pain, revenue, retention, first-response |
| 7 | **Customer-side value** | Faster response; clearer next step; fewer back-and-forth |
| 8 | **Broker-side value** | Less manual triage; fewer re-asks; clearer next move; no lost follow-ups |
| 9 | **Workbench expectations** | Queue, status, follow-up memory, reopen, Collected/Still needed chips |
| 10 | **Handoff expectations** | Case focus, Your next move, Human confirmation when needed, draft to edit |
| 11 | **Data/metrics to measure** | Conversations, handoffs, scenario mix, broker feedback (5 questions) |
| 12 | **How founder explains trial** | "1-week pilot: paste messages → structured case → next move → draft. You review and send. No auto-send." |
| 13 | **Setup before trial** | Run trial_readiness_check.sh; run_demo_local.sh; Load founder demo queue |
| 14 | **Trial success** | Broker completes 5+ conversations across 3+ scenario types; can answer value validation questions |
| 15 | **Trial failure/friction** | Broker cannot understand flow; output unreliable; cannot tell real-office applicability |
| 16 | **Logs/observations** | Day-by-day: conversations, handoffs, scenario mix, notes (see Trial Metrics Spec) |
| 17 | **Acceptable product weaknesses** | No inbox sync; manual paste; no carrier API; broker must copy draft to WeChat/email |
| 18 | **Improve after trial** | Per broker feedback; likely: inbox integration, OCR, carrier lookup |

*End of 10–20 Point Breakdown*
