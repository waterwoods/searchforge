# 试用与付费条款（一页）

**产品：** Unified Intake · 办公室工作台  
**版本：** V1 · 2026-06-01  
**适用：** 加州汽车保险经纪办公室试用与付费试点

---

## 试用

| 项目 | 说明 |
|------|------|
| **试用时长** | 7 天，免费 |
| **试用内容** | 完整功能：粘贴、case 整理、队列、草稿回复 |
| **试用要求** | 至少粘贴 3 条真实客户消息；记录使用感受 |
| **试用结束** | 第 7 天决定是否付费继续 |

---

## 付费方案

| 方案 | 月费 | 说明 |
|------|------|------|
| 入门版 | $49/月 | 经纪本人使用 |
| 标准版 | $99/月 | 经纪 + 助理使用 |

- 第一单按自然月计费（例：6 月 15 日开始 → 付到 7 月 14 日）
- 付费方式：Zelle / Venmo / 微信（创始人发 invoice）
- 无自动扣款；每月 invoice 手动支付

---

## 支持

| 项目 | 说明 |
|------|------|
| **支持渠道** | 微信 / 邮件 |
| **响应时间** | 工作日 24 小时内 |
| **支持范围** | 使用方法、case 输出问题、系统故障 |
| **不包含** | 保险业务咨询、carrier 操作、法律建议 |

试用期间和付费期间支持级别相同。

---

## 使用期望

**你会得到：**
- 粘贴客户消息 → 结构化 case + 草稿回复
- case 队列和优先级
- 创始人微信支持

**你需要做：**
- 自己粘贴消息（v1 不连微信）
- 检查并修改草稿后再发到微信
- 试用期间记录有没有省时间

**我们不保证：**
- 每条输出 100% 正确（请自行核对后再发）
- 覆盖所有保险场景
- 7×24 系统不停机（故障时创始人 24h 内响应）

---

## 数据

| 项目 | 说明 |
|------|------|
| **数据归属** | 你粘贴的客户消息和 case 内容归你 |
| **存储** | 云端数据库；仅创始人和你的账号可访问 |
| **试用结束不付费** | 数据保留 30 天，可申请导出；之后删除 |
| **付费取消后** | 数据保留 30 天，可申请导出；之后删除 |
| **不会** | 出售你的数据；用于训练对外模型 |

---

## 取消

| 情况 | 怎么做 |
|------|--------|
| **试用期间** | 随时停止，不收费，无需手续 |
| **付费后取消** | 提前 7 天微信告知创始人 |
| **当月已付** | 不退款；可用到当月结束 |
| **取消后** | 30 天内可导出数据 |

---

## 付款流程

1. 试用第 7 天：创始人发 invoice（$49 或 $99）
2. 你确认方案 → 收到 invoice
3. Zelle / Venmo / 微信付款
4. 创始人确认收款 → 下个月继续用
5. 下月 invoice 提前 3 天发送

- **Day 0：** 30 分钟带练（约时间）
- **Day 7：** 15 分钟价值确认 + 付费决定
