# Last-Mile Trial Readiness — 10–20 Point Breakdown

**Sprint:** Trial Execution Readiness + Last-Mile Hardening  
**Created:** 2026-03-18  
**Purpose:** Concrete last-mile trial-readiness points.

---

## Concrete Points

| # | Point | Decision |
|---|-------|----------|
| 1 | **Founder pre-trial checklist** | 7 steps: trial_readiness_check → run_demo_local → open URL → Load founder demo queue → SIM1–SIM3 → copy observation log → read workflow |
| 2 | **Broker trial onboarding steps** | Open URL → Load founder demo queue → Run SIM1, SIM2, SIM3 → Paste first real message → Start case → Verify handoff |
| 3 | **Assistant daily workflow steps** | Paste → Triage → Multi-turn until handoff → Review case card → Edit draft → Copy to client → Update status → Reopen when reply |
| 4 | **Talk to Agent trust/readiness behavior** | Clear path; handoff-ready immediately; broker sees "Customer wants human"; no wrong routing |
| 5 | **Handoff next-action visibility** | Bold, top of case card; one operational sentence; concrete action verbs |
| 6 | **Recent message visibility expectations** | After append: "Just updated with customer follow-up" badge; queue shows last update |
| 7 | **Correction/already_sent/context visibility** | Badge when customer said sent or corrected; "Verify receipt" when applicable |
| 8 | **Edge cases in scope** | Talk to Agent; correction; already_sent; next move prominence; Day 1 clarity |
| 9 | **Edge cases deferred** | LC-AC3 handoff timing; full add-driver multi-turn; inbox sync; OCR |
| 10 | **Observation log usage** | Day-by-day: conversations, handoffs, scenario mix, notes; post-trial: 5 value questions |
| 11 | **Feedback categorization** | Trust-breaking / High / Medium / Low friction |
| 12 | **What counts as trust-breaking** | Wrong next move; Talk to Agent routes wrong; auto-send confusion; Collected wrong + no Human confirmation; correction invisible |
| 13 | **What counts as acceptable trial friction** | Turn 1 occasionally slow; manual paste; broker copies draft to WeChat; some scenarios need polish |
| 14 | **What triggers immediate iteration after trial** | Trust-breaking observation; broker says "I can't use this" |
| 15 | **Product/UI/backend adjustments justified now** | Next-action prominence; correction/already_sent badge; observation template with friction classification |
| 16 | **Intentionally deferred** | Inbox sync; OCR; carrier API; multi-tenant; Stripe; LC-AC3 |
| 17 | **What makes package truly trial-executable** | Founder can run with one checklist; broker has Day 1 flow; handoff usable; observations convert to fixes |
| 18 | **What would make it closer to production after trial** | Inbox integration; OCR; carrier lookup; auth; billing |
