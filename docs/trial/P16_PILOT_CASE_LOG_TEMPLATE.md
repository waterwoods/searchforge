## Field definitions

| Column | Definition |
|--------|------------|
| **Case ID** | CK-001 … CK-010 (sequential) |
| **Customer Type** | e.g. 新客户 / 现有保单 / 青少年司机 / 英文客户 / 急单 |
| **Start Time** | When broker opened WeChat thread or pasted into workbench |
| **End Time** | When broker copied draft or closed case |
| **Duration** | End − Start (minutes) |
| **Would broker reread WeChat?** | Without this tool, would he scroll back through bubbles? YES = tool reduces reread |
| **Append Used?** | Did customer return later and broker append to same case? |
| **Any Missing Fields?** | Did Collected/Still needed miss something broker knew from WeChat? |
| **Any Wrong Next Step?** | Was broker_next_step misleading or regressive (e.g. re-ask delivery after append)? |
| **Minutes Saved** | Estimate vs manual: read + extract + draft + office handoff notes |
| **Comments** | Verbatim broker quote, friction, draft edit level (小改/中改/大改) |
