# 经纪人试用 — 一页说明

**试用名称：** Real Broker Trial Package（1周试用）

---

## 你在试用什么

- **入口：** 粘贴客户发来的消息（微信/邮件）
- **系统做：** 整理成结构化 case，有下一步动作、收集了什么、还缺什么、草稿回复
- **你做：** 确认后复制发给客户；不自动发送

---

## 5个核心场景

| # | 场景 | 说明 |
|---|------|------|
| 1 | 取消风险 / 付款失败 | 紧急，当天处理 |
| 2 | 缺材料 / 客户说发过了 | 核实收到，避免重复要 |
| 3 | 加车报价 | 多轮收集年份、车型、zip |
| 4 | 保费审核 | 续保、降费 |
| 5 | 事故报案 | 首次响应指引 |

---

## 第一天怎么用

1. 打开 /workbench/unified-intake
2. 点 **Load founder demo queue** — 加载13个示例 case
3. 打开 **Simulation Assistant** — 跑 SIM1、SIM2、SIM3
4. 贴一条真实消息（或点 Need an example?）— 创建一个 case
5. 看 Case focus、Your next move、Collected、Still needed
6. 编辑草稿，复制发给客户
7. 更新状态，保存 follow-up

---

## 试用成功 = 你能回答

- 哪个场景对你办公室最有用？
- 哪部分还不放心？
- 会不会省时间？
- 下一步最想要什么功能？
