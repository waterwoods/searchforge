# Externalize vs Keep (Engine)

| Item | Verdict |
|------|---------|
| `stitched` materials-sent / prospective-send / why-still-chasing | **Externalized** (`handoff_phrases.json`) |
| Handoff keys `add_car`, `other_*`, `customer_requested_human` | **Already config** |
| `reply_overrides` / industry templates | **Already config** |
| `ui_copy` | **Already config** |
| Append boundary Chinese continuity | **Keep in code for now** (defer P1) |
| Add-car coverage overlay lines | **Keep in code for now** |
| Intent markers / extraction / LLM | **Keep in code** |
