## 2. Scoring Process

1. Score each candidate on 7 dimensions (1–10)
2. Combine into qualitative ranking (top / mid / defer)
3. Challenge: Are we overvaluing technical novelty? Undervaluing trial?
4. Adjust if needed
5. Produce single recommendation

---

## 3. Challenge/Review Loop

**Loop 2 questions:**
- Are we overvaluing technical novelty?
- Are we undervaluing something that helps immediate paid trial?
- Are we ignoring broker workflow pain?
- Are we mistakenly prioritizing a glamorous but expensive feature?

---

## 4. Final Recommendation Process

1. Rank all candidates
2. Select #1 as best next sprint
3. Select #2 as second-best
4. List defer items with rationale
5. Explain why #1 has best ROI now
6. List explicit "avoid now" items
