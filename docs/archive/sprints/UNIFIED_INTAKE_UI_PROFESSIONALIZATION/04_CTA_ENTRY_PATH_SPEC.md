# CTA / Entry Path Spec

**Sprint**: Unified Intake UI Professionalization

---

## Primary Entry Actions (in order)

1. **获取报价** — Add car / new quote
2. **保单变更** — Remove car, policy change
3. **报事故** — Claim intake
4. **付款 / 账单** — Payment, cancellation risk
5. **上传材料** — Missing document
6. **联系人工** — Talk to agent

---

## Button / Module Treatment

- **Option A**: Card-style modules — each action in its own bordered card with icon + label
- **Option B**: Larger, deliberate buttons in a grid — not tiny chips
- **Preferred**: Card-style or prominent buttons; NOT scattered small chips
- **Selected state**: Clear primary color; not subtle

---

## Reducing User Hesitation

- Label actions clearly in Chinese
- "今天有什么可以帮您？" as opener
- Primary actions visible immediately; no need to scroll
- Free input labeled as "不确定选哪个？直接输入或粘贴"

---

## Guided Feel

- Clear hierarchy: actions first, free input second
- Helper text: "点击上方选项开始，或直接输入您的问题"
- Remove or de-emphasize "模拟演示" on customer-facing first screen
