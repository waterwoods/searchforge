## What Andy Should Inspect After This Sprint

1. **First-screen structure**
   - Does Trust/Hero appear first?
   - Are primary actions (获取报价, 保单变更, etc.) clearly the main path?
   - Is free input clearly secondary?

2. **Visual professionalism**
   - White cards on light gray background?
   - No dark-theme color bugs (white text on white)?
   - Clear card boundaries and spacing?

3. **Trust messaging**
   - Is "办公室会跟进" or equivalent visible?
   - Does the page feel like a formal insurance service entry?

4. **Demo vs product**
   - Is "模拟演示" de-emphasized or relocated?
   - Does the page feel like something you'd show a real broker?
