# Acceptance / SLA Criteria

**Sprint:** Workbench Handoff Readiness

---

## 1. Handoff Readability

- [ ] Broker can see recent customer messages (2–3) without parsing source_text
- [ ] Case focus, lifecycle, next move visible above the fold
- [ ] Collected / still needed chips visible when structured fields present

---

## 2. Office Usefulness

- [ ] Broker can tell "what should I do next?" within 5 seconds of opening case
- [ ] Correction / "already sent" badge visible when applicable
- [ ] Full conversation available but not dominating first view

---

## 3. Reduction of Re-reading

- [ ] Recent customer messages reduce need to scroll through full conversation
- [ ] Structured chips reduce need to parse conversation_summary

---

## 4. Visual Clarity

- [ ] Layout feels more like office work tool, less like debug screen
- [ ] No regression in existing case card behavior

---

## 5. Acceptable to Defer

- Field values (e.g. 2025, Honda CR-V) in chips — still in summary
- Other flows' structured expansion
- Queue-level filtering/sorting enhancements

---

*End of acceptance criteria*
