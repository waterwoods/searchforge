# Unified Intake Focus Mode — Acceptance / SLA Criteria

**Sprint**: Unified Intake Focus Mode + Customer-First Layout

---

## What Counts as Better Focus

- Left nav does not dominate the view on Unified Intake
- Central content area feels like the main surface
- Fewer competing visual elements
- Page hierarchy is obvious: customer starts here → office reviews later

---

## What Counts as Better Customer-Entry Prominence

- Customer Entry area is visually dominant when that tab is active
- Input box is larger or more obvious than before
- Title/subtitle clearly state "for customers"
- Call to action (submit/send) is prominent

---

## What Counts as Better Role Separation

- Customer Entry tab/label reads as customer-facing
- Broker Workbench tab/label reads as office-facing
- Intro or copy reinforces who each area is for
- No confusion about "who uses this"

---

## What Counts as Too Cluttered

- Left nav with 10+ items visible and competing for attention
- Header with lab metrics (P95, Recall, QPS) when broker is the audience
- Multiple banners or alerts above the fold
- Simulation Assistant feels like a primary tool rather than companion

---

## What Counts as Acceptable vs Unacceptable Demo-Page Distraction

| Acceptable | Unacceptable |
|------------|--------------|
| Collapsible product intro | Persistent lab metrics in header |
| One "show product info" link | Full left nav with RAG Lab, Agent Studio, etc. |
| Simulation Assistant as secondary button | Simulation Assistant as equal to Customer Entry |
| Broker Workbench as secondary tab | Both tabs equal weight with no role hint |

---

## Pass/Fail for Sprint

- **Pass**: Page feels more focused; customer entry more prominent; role separation clearer; no new clutter
- **Fail**: Layout unchanged; or new clutter introduced; or role confusion increased
