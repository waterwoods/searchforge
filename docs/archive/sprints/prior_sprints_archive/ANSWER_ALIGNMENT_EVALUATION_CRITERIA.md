# Answer Alignment — Evaluation / SLA Criteria

**Sprint:** Answer Alignment Audit + Optimization Direction  
**Created:** 2026-03-15

---

## 1. Did the Response Answer the Direct Ask?

| Criterion | Pass | Fail |
|-----------|------|------|
| User asked “怎么办” | Reply states what to do (e.g. 发通知/截图，今天尽快处理) | Reply only asks for more info without answering |
| User asked “多少钱” | Reply acknowledges vehicle + asks for year/zip to quote | Reply says “请提供更多信息” or similar |
| User asked “什么意思” | Reply explains (or says 发我帮你看) | Reply ignores the question |
| User asked “最要紧做什么” | Reply answers urgency / priority | Reply gives generic handoff only |
| User asked “这些够了吗” | Reply confirms or clarifies | Reply repeats same ask |

---

## 2. Did It Collect Missing Info Appropriately?

| Criterion | Pass | Fail |
|-----------|------|------|
| After answering | Asks for 1–2 next things | Asks for 6 things at once |
| Add-car | Asks year, zip, delivery in order | Asks everything or nothing |
| Payment risk | Asks for notice/screenshot | Asks for “more context” |
| Missing doc | Names the item + asks for resend | Generic “please send documents” |

---

## 3. Did It Feel Natural and Helpful?

| Criterion | Pass | Fail |
|-----------|------|------|
| Tone | Office-natural, conclusion-first | Robotic (“Thank you for reaching out”) |
| Length | 1–3 short sentences | Long paragraph |
| Acknowledgment | “好的，宝马X5。” before ask | No acknowledgment |
| Empathy (claim) | “刚出事故一定很着急，先别慌” | Generic or missing |

---

## 4. Did It Over-Hand-Off?

| Criterion | Pass | Fail |
|-----------|------|------|
| Turn 1 direct question | Answer + ask for next thing | Jump to “办公室会尽快处理” without answering |
| Turn 2 clarification | Answer the question + handoff suffix | Generic handoff only |
| Turn 3 “最要紧做什么” | Answer urgency + handoff | “您说的情况已整理好了” only |

---

## 5. Did It Stay Too Generic?

| Criterion | Pass | Fail |
|-----------|------|------|
| Add-car | Asks year/model/zip | “这段内容还不够完整” |
| Payment failed | States urgency + asks for notice | “Please provide more context” |
| Notice confusion | Asks for full notice | “请提供更多信息” |
| Document confusion | Explains term + asks for doc | Generic fallback |

---

## 6. Classification Labels for Audit

| Label | Meaning |
|-------|---------|
| **answered well** | Direct ask addressed; natural; appropriate collect |
| **partially answered** | Some of the ask addressed; minor gaps |
| **mostly missed** | Core ask not addressed; generic or wrong direction |
| **wrong direction** | Answered something else; user would feel 答非所问 |
