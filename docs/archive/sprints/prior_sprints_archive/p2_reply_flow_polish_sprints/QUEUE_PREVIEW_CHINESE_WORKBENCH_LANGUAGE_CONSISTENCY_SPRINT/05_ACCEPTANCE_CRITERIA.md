# Acceptance Criteria

**Sprint:** Queue Preview Chinese + Workbench Language Consistency Sprint  
**Created:** 2026-03-20

---

## Language consistency

- [ ] Queue readiness labels (on cards) are office-oriented Chinese
- [ ] Compact queue preview strings are Chinese (已收集/还缺, flow names in Chinese)
- [ ] Case focus tags (加车报价, 事故报险, etc.) are Chinese where broker-facing
- [ ] Structured field labels in case detail use Chinese for broker scan
- [ ] Case report one-liner uses 可交办公室 / 信息收集中
- [ ] Draft readiness uses 需您修改后再发 / 可审核草稿
- [ ] Copy case snapshot output uses Chinese labels

## Broker readability

- [ ] Broker can scan queue cards without encountering mixed English/internal wording
- [ ] Case detail section headers and field names feel office-appropriate
- [ ] No debug-style or engineering-heavy phrasing in visible UI

## Stronger product polish

- [ ] Workbench feels less like a prototype and more like an office tool
- [ ] Vocabulary is consistent across queue cards, case detail, and copy output

## No risky behavior changes

- [ ] Demo queue loading behavior unchanged
- [ ] No backend or API changes
- [ ] Build passes; no new runtime errors
