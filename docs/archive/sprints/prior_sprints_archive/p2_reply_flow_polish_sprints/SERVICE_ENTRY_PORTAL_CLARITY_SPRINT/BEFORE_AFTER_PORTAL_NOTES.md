# Before / after — portal comparison (concise)

## Top of customer tab

| Before | After |
|--------|--------|
| 客户服务入口 | 客户统一受理与报送 |
| welcome 段落 + 固定「1–3 个工作日」拼接 | 单一 `portal_service_tagline`（报送→记录→办公室） |

## First screen

| Before | After |
|--------|--------|
| 今天有什么可以帮您？ | 请先选择办理类型，或直接填写下方报送内容。 |
| 选择您的需求 | 办理类型（点选后开始本条业务） |
| 获取报价（默认按钮） | 办理加车报价 |

## Active intake

| Before | After |
|--------|--------|
| （无区块标题） | 本条办理过程与办公室整理 |
| 您 / 办公室 | 您的报送 / 办公室整理回复 |
| 正在整理，马上就好... | 办公室正在整理您的报送，请稍候… |
| 整理中 + （实时更新） | 当前受理进度 + （状态随报送更新） |
| 发送 | 提交补充 |
| 提交（首条） | 提交报送 |

## Handoff

| Before | After |
|--------|--------|
| {办公室}回复摘要 | 办公室办理摘要 |

## Chrome

| Before | After |
|--------|--------|
| 汽车保险客户统一入口 | portal_brand_tagline（可配置） |
| 客户入口 — 客户 | 客户报送 — 受理入口 |
| 已恢复对话 | 已恢复未完成的报送 |

## Unchanged (by design)

- Message-thread **layout** (bubbles).
- Triage **logic** and API contracts.
- Add-car **ribbon** structure and handoff **card** structure.
