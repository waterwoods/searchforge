# Founder / Broker Trial Execution Blueprint

**Sprint:** Founder / Broker Trial Execution Sprint  
**Product:** SearchForge → Chen Kui Insurance Unified Entry  
**Created:** 2026-03-20

---

## 1. Why this is the right time

The product has crossed from “feature accumulation” to **integration risk**: customer entry, Add-Car, quote-ready signals, contact identity, attachment-ready-lite, workbench handoff, and materials-sent handling now exist as separate strengths. The open question is **whether they read as one believable commercial intake + case tool** when used continuously—not whether another module can be added.

A founder/broker-style trial at this moment:

- Stress-tests **Page + Flow + State + Handoff** together (the four backbones).
- Surfaces **trust-breaking** gaps that scripts alone miss (tone, scan speed, vague next steps).
- Produces **fix-now** decisions grounded in usage, not backlog appetite.

---

## 2. What this sprint evaluates

| Area | Question |
|------|----------|
| Customer entry | Does the hub feel formal and client-safe, not internal demo? |
| Add-Car | Does the flagship path feel like a real quote intake? |
| State | Do quote-ready / almost-ready / need-more / follow-up read correctly under time pressure? |
| Workbench | Can a founder scan the queue and open a case to a clear next action in seconds? |
| Handoff | Does the office receive a scan-friendly, trustworthy packet? |
| Continuity | Do multi-turn and append flows match broker mental models? |

---

## 3. What this sprint strengthens

- **Trial execution discipline:** blueprint → run → classify → fix highest ROI → retest.
- **Honest friction taxonomy:** fix-now / fix-next / acceptable-for-trial / defer.
- **Evidence for broker conversations:** what to show, what to caveat.

---

## 4. What this sprint intentionally does not do

- New product direction or large net-new features  
- OCR, carrier APIs, quote engines  
- Architecture redesign  
- CRM / multi-tenant / enterprise ticketing  
- Cosmetic polish that does not change trial trust or rework
