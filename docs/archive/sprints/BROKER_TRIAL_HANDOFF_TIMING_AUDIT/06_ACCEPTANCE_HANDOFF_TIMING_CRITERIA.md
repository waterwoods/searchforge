# Acceptance / Handoff Timing Criteria

**Sprint:** Broker Trial Simulation + Handoff Timing Audit  
**Purpose:** Practical criteria for acceptable handoff timing.

---

## Acceptable Handoff Timing

- Main case goal clear enough
- Collected information sufficient for broker to act
- User had fair chance to finish key details (2+ turns for non-add-car; field-based for add-car)
- No handoff T1 for vague ("帮我", "在吗")
- Talk-to-agent handoff T1

---

## Acceptable Completeness

- Add-car: year+model + zip + (delivery or driver)
- Missing doc: item + sent status
- Premium: policy/bill or remove-vehicle intent
- Payment: notice + proof/screenshot when claimed

---

## Acceptable Broker Clarity

- broker_next_step: one operational sentence
- conversation_summary: intent + collected + latest
- Correction reflected when customer corrects

---

## OK to Defer for First Trial

- Perfect 3-turn handling for every category
- Continuation markers ("还有一个问题") delaying handoff
- Observation log from real trial will inform fix-next

---

*End of Criteria*
