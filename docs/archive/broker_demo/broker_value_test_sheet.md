# Broker Value Test Sheet

**Purpose**: Simulate realistic broker usage during value-validation meeting.  
**User**: Andy (operator) + broker (e.g., 陈魁)  
**Duration**: ~15 min for 5 scenarios

---

## How to use

1. Open demo at `http://localhost:5173/demo` (or deployed URL)
2. For each scenario, click the recommended question or type it
3. Broker rates: **Saves time?** (Y/N) | **Usable answer?** (Y/N) | **Would use again?** (Y/N)
4. Note any gaps or suggestions
