# Unified Intake — Broker One-Pager

**For:** California auto insurance brokers (e.g., Chen Kui)  
**Product:** Unified Intake + Broker Workbench  
**Trial:** 7 days free → optional paid pilot

---

## What it is

Unified Intake turns messy customer messages into **one structured case** — with urgency, your next move, what was collected, what's still needed, and a **draft reply you review before sending**.

**You stay in control. Nothing is auto-sent.**

---

## Why you would pay

| Problem today | What Unified Intake does |
|---------------|--------------------------|
| Urgent notices buried in WeChat | Same-day action cases surface first |
| Re-asking for info customer already sent | **Collected** / **Still needed** chips |
| Starting over on every follow-up | Reopen cases; paste new messages; resume |
| Writing the same reply from scratch | Editable draft ready to copy to WeChat |

---

## How to try it (15 minutes)

1. Open: **/workbench/unified-intake**
2. Click **Load founder demo queue** — sample cases load
3. Open the **cancellation risk** case first — see urgency and same-day action
4. Try **Missing document** and **Add-car quote** cases
5. Paste one real customer message (or use **Need an example?**)

**Ask yourself:** Which scenario felt most useful? What still feels risky?
