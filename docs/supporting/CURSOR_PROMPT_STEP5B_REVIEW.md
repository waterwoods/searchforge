# 🧠 Cursor Prompt: Step5B Longrun 成果验收 & 质量评估

我刚刚停止了 Step5B 的 1.5–2 小时长跑任务（`run_step5b_discovery_longrun_2h.sh`）。
请你帮我做一次完整的 Run 结果验收与总结，包括：

## 任务清单

### 1. 自动定位最新运行目录
- 扫描 `results/auto_insurance_discovery/runs/` 目录
- 找到最新的时间戳目录（格式：`YYYY-MM-DD_HHMMSS`）
- 确认该目录包含以下文件：
  - `candidates.json` - 所有发现的候选来源
  - `passing.json` - 通过验证的来源
  - `REPORT.md` - 基础报告
  - `verify_corpus.jsonl` - 验证爬取结果（如果存在）
  - `run_summary.json` - 运行元数据
  - `CHECKPOINTS.md` - 检查点历史
  - `RUN_LOG.txt` - 完整执行日志

### 2. 汇总统计信息
- **发现的候选来源总数**：从 `candidates.json` 读取
- **通过验证的来源数**：从 `passing.json` 读取
- **验证文档数**：从 `verify_corpus.jsonl` 统计行数（如果存在）
- **运行时长**：从 `run_summary.json` 读取
- **按域名分组统计**：每个域名发现了多少个候选、通过了多少个

### 3. Top 10 质量最高的来源
按以下综合指标排序：
- **去重后可抓取页面数**（从 `verify_corpus.jsonl` 统计每个域名的唯一页面数）
- **可用性**（`blocked_by_robots = false`，`score >= 15.0`）
- **内容质量**（`content_length`、`score`）
- **robots.txt 允许情况**

输出格式：
```
1. [标题] (score: X.X)
   - URL: [url]
   - Domain: [domain]
   - 可抓取页面数: [count]
   - 内容长度: [chars]
   - 评分理由: [reasons]
```

### 4. Robots.txt 阻挡分析
- 统计所有 `blocked_by_robots = true` 的候选
- 按域名分组，列出被阻挡的域名列表
- 特别标注种子域名（如 `statefarm.com`）是否被阻挡
- **建议**：
  - 如果种子域名被阻挡 → 建议从种子列表中移除
  - 如果某个域名大量候选被阻挡 → 建议降低该域名的优先级或移除

### 5. 异常情况检查
检查以下问题：

#### 5.1 卡死域名
- 检查 `RUN_LOG.txt` 中是否有长时间无响应的域名
- 检查是否有域名导致超时重试过多

#### 5.2 超时重试过多
- 统计 `RUN_LOG.txt` 中的超时/重试信息
- 列出重试次数超过 3 次的域名

#### 5.3 单一域名占比过高
- 计算每个域名在 `candidates.json` 中的占比
- 如果某个域名占比 > 30%，标记为警告

#### 5.4 发现质量下降
- 分析 `CHECKPOINTS.md` 中的检查点数据
- 检查后期发现的候选质量是否明显下降（score 趋势）
- 检查后期是否出现大量低分候选（score < 10）

#### 5.5 其他异常
- 检查 `run_summary.json` 中的 `exit_code` 是否为 0
- 检查是否有文件缺失或损坏
- 检查运行时间是否接近配置的最大运行时间（可能被提前终止）
