# 办公室消息整理助手 — 一页说明

**给：** 加州汽车保险经纪办公室（如陈魁）  
**产品名：** Unified Intake · 办公室工作台  
**试用：** 7 天免费 → 可选付费继续

---

## 1. 这是什么？

一个帮你处理客户微信/邮件消息的小工具。

你把客户发来的原文**粘贴**进去 → 系统整理成一条**办公室 case**：  
今天要不要处理、下一步做什么、已经收集了什么、还缺什么、**草稿回复（你改完再发）**。

**不自动发送。你始终掌控。**

---

## 2. 给谁用？

| 谁 | 怎么用 |
|----|--------|
| **经纪本人** | 处理取消通知、缺文件、加车报价等紧急消息 |
| **办公室助理** | 同样流程；帮你先整理，你再确认 |

适合：小型加州汽车保险办公室，客户以微信为主，每天 20–50 条消息。

---

## 3. 解决什么问题？

| 现在的痛点 | 这个工具做什么 |
|------------|----------------|
| 紧急消息埋在微信里 | 「今天要处理」的 case 排在前面 |
| 客户已经发过信息，还要再问一遍 | 一眼看到「已收集 / 还缺什么」 |
| 每条消息从头写回复 | 有草稿，改一下复制到微信 |
| 跟进时要重新读整段对话 | 打开 case，粘贴新消息，接着做 |

---

## 4. 为什么比只用微信好？

微信是聊天。这个工具是**办公室工作台**：

- 把 messy 消息变成**结构化 case**（不是聊天记录）
- 标出**紧急程度**和**你今天该做什么**
- 列出**已经有什么、还缺什么**——不用自己记
- 给你**可编辑草稿**——不用从空白开始写

微信仍然是你发消息的地方。这个工具帮你**整理和起草**，不替你做决定。

## 5. 为什么值 $49/月？

**$49 = 入门版（经纪本人用）**

- 适合：每周有 3–5 条紧急消息（取消、付款失败、缺文件）
- 如果这类消息**每周能帮你省 30 分钟以上**，$49 不到一个助理一小时的钱
- 包含：粘贴整理、case 队列、草稿回复、试用期间创始人微信支持

**怎么判断值不值：** 试用 7 天，看取消或缺文件有没有真的省时间。

## 6. 什么时候值 $99/月？

**$99 = 标准版（整个办公室用）**

- 适合：经纪 + 助理都在用；取消、缺文件、加车至少两类场景都跑顺
- 如果办公室**每天少花 10–15 分钟**在重复读消息和写回复上，$99 合理
- 包含：$49 全部功能 + 助理可以独立使用 + 优先支持

**怎么判断：** 试用结束时，助理也愿意用，且至少两类场景你复制过草稿。

## 7. 试用 7 天会发生什么？

| 天 | 做什么 |
|----|--------|
| **第 0 天** | 创始人 30 分钟带练：粘贴一条真实消息，完成第一次复制草稿 |
| **第 1–2 天** | 自己粘贴 1–2 条真实客户消息；记录有没有省时间 |
| **第 3–5 天** | 每天 2–3 条真实 case；试试跟进粘贴 |
| **第 7 天** | 15 分钟通话：聊值不值、选 $49 或 $99、或先不付费 |

**你需要做的：** 粘贴真实消息、看 case、改草稿、复制到微信。  
**你不需要做的：** 不用连微信、不用上传截图、不用学复杂设置。
