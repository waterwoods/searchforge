# Return Policy

## Return Time Window

Items can be returned within **30 days** from the delivery date. The return request must be initiated before the 30-day deadline expires.

## Item Condition Requirements

To be eligible for return, items must meet the following conditions:

- **Unused or minimally used**: Items should be in their original condition
- **Original packaging**: Items should be returned in their original packaging when possible
- **All accessories included**: All original accessories, manuals, and documentation must be included

## Special Categories

### Non-Returnable Items

The following categories are **not eligible for return**:

- Customized or personalized items
- Items that have been used extensively or show significant wear
- Items without original packaging (unless damaged or defective)
- Digital products or downloadable content

### Exceptions

Items that are **damaged or defective** may be eligible for return even if they do not meet the standard condition requirements, subject to verification.

## Return Process

1. Initiate return request through customer service or online portal
2. Receive return authorization and shipping label
3. Package item securely with original packaging
4. Ship item back within 7 days of return authorization
5. Refund processed within 5-10 business days after item is received and verified
